Vault upload samples (synthetic, non-PHI)
========================================

Use these with Epistemic Vault → Submit Documents after you start a session.
They are plain text so the server can store a text snippet on the PTV artifact node.

Suggested document types in the UI when uploading:
  - lab_results_sample.txt       → Document type: Lab Results
  - clinical_note_visit.txt      → Clinical Note
  - symptom_diary_stub.txt       → Other (or Clinical Note)
  - medication_list_stub.txt     → Prescription
  - promis_style_stub.json       → Other (JSON body is still stored as file bytes)

Do not use real patient identifiers in copies of these files.
