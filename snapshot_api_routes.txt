## Overview
The repository implements three FastAPI applications representing different architectural approaches: MongoDB+ChromaDB, PostgreSQL+pgvector, and a shared journal component. Each provides comprehensive medical diagnosis APIs with sophisticated security, authentication, and AI-powered analysis capabilities.

## Application Architecture

### App Version 1: MongoDB + ChromaDB (server/api/app.py)
**Database**: MongoDB for user data, ChromaDB for vector search
**Vector Engine**: ChromaDB with OpenAI embeddings
**Port**: Configurable (default 8000)
**Key Features**: Legacy-compatible with extensive ChromaDB integration

### App Version 2: PostgreSQL + pgvector (server/api/app_postgres.py)
**Database**: PostgreSQL with pgvector for unified storage
**Vector Engine**: PostgreSQL pgvector with cosine similarity
**Port**: Configurable (default 8001)
**Key Features**: Modern unified database approach with ICD-10 integration

### App Version 3: Shared Journal Component (server/api/journal.py)
**Purpose**: Reusable journal functionality for both applications
**Integration**: Dual database support with fallback mechanisms
**Features**: AI-powered analysis with medical domain expertise

@app.middleware("http")
async def security_middleware(request: Request, call_next):
    # Block access to sensitive files
    sensitive_paths = [
        "/.env", "/.git", "/server/", "/node_modules/",
        "/package.json", "/yarn.lock", "/.gitignore"
    ]
    
    if any(request.url.path.startswith(path) for path in sensitive_paths):
        raise HTTPException(status_code=404, detail="Not found")
    
    # Security headers
    response = await call_next(request)
    response.headers["X-Content-Type-Options"] = "nosniff"
    response.headers["X-Frame-Options"] = "DENY"
    response.headers["X-XSS-Protection"] = "1; mode=block"
    response.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
    
    return response

@app.exception_handler(HTTPException)
async def http_exception_handler(request: Request, exc: HTTPException):
    """Custom HTTP exception handling with logging"""
    
    # Log error details
    logger.error(f"HTTP {exc.status_code}: {exc.detail} - {request.url}")
    
    # Sanitize error response for security
    if exc.status_code == 500:
        detail = "Internal server error"
    else:
        detail = exc.detail
    
    return JSONResponse(
        status_code=exc.status_code,
        content={"detail": detail, "timestamp": datetime.utcnow().isoformat()}
    )

@app.exception_handler(ValidationError)

    """Pydantic validation error handling"""

        status_code=422,

### Encrypted Logging System
```python
class EncryptedLogger:
    def __init__(self, encryption_key: str):
        self.encryption_key = encryption_key.encode()
        self.cipher_suite = Fernet(base64.urlsafe_b64encode(self.encryption_key[:32]))
    
    def log_encrypted(self, level: str, message: str, user_id: Optional[str] = None):
        """Log sensitive information with encryption"""
        
        log_entry = {
            "timestamp": datetime.utcnow().isoformat(),
            "level": level,
            "message": message,
            "user_id": user_id
        }
        
        encrypted_entry = self.cipher_suite.encrypt(
            json.dumps(log_entry).encode()
        )
        
        # Store encrypted log entry
        with open("encrypted_logs.bin", "ab") as f:
            f.write(encrypted_entry + b"\n")
```
