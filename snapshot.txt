EXECUTIVE SUMMARY
================================================================================

2ndOpinionMD is an AI-powered medical diagnostic support platform focused on 
autoimmune disease diagnosis. The system combines a comprehensive Medical 
Knowledge Graph (MKG) with Retrieval Augmented Generation (RAG) to provide 
second-opinion analysis for complex medical conditions.

Core Capabilities:
- AI-powered diagnosis from symptom descriptions using hybrid RAG (TS + ANN + fusion)
- Health journaling with AI-generated insights (2OPMD Diagnostic Terrain System)
- Medical knowledge search across 100,000+ codes, 10,000+ rare diseases, guidelines
- Clinical coding abstraction (ICD-10-CM/PCS, SNOMED, LOINC, RxNorm)
- Pattern recognition using STAX levels and Zones framework

Technology Stack:
- Backend: FastAPI (Python 3.12) with async PostgreSQL
- Database: PostgreSQL 14+ with pgvector extension
- AI/ML: OpenAI (GPT-4, text-embedding-3-small)
- Frontend: React (CRA-based) with Node.js v18
- Deployment: Docker containers with Nginx reverse proxy

================================================================================
RAG ARCHITECTURE
================================================================================

Query Flow:
1. Term Extraction
   - ICD-10 codes via regex (I21.4, E11.9)
   - LOINC codes (2345-7)
   - SNOMED concepts
   - Drug names (aspirin, heparin)
   - Symptom keywords

2. Source Routing
   - MKG-first expansion via SQL lookups
   - ehr_mimic4.d_icd_diagnoses for ICD labels
   - rag_corpus by source (loinc, rxnorm, snomed, hpo)

3. Hybrid Retrieval
   - TS (BM25): ts_rank with plainto_tsquery
   - ANN (Dense): pgvector cosine similarity (<#>)
   - Fusion: RRF scoring with configurable weights (0.7 ANN, 0.3 BM25)

4. LLM Synthesis
   - Context assembly from top-k matches
   - OpenAI GPT-4/GPT-4o-mini for response generation
   - Structured JSON output with citations

5. Citation Governance
   - Evidence title matching
   - Code enrichment from matches
   - Missing citation explanation

Embedding Configuration:
- Model: text-embedding-3-small (1536 dimensions)
- Batch size: 256
- ANN Index: ivfflat with lists=200, probes=8

================================================================================
GUIDELINES INGESTION PIPELINE
================================================================================

Sources:
- VA/DoD Clinical Practice Guidelines
- CDC Guidelines (Opioid, etc.)
- WHO Essential Medicines List
- WHO Expert Committee Reports
- NICE Guidelines (UK)

Pipeline Steps:
1. Fetch: Download PDFs/HTML from source
2. Parse: Extract sections with 2000-char chunks, 250-char overlap
3. Load: Insert into guidelines.* tables
4. RAG Upsert: Copy to rag_corpus with source tag
5. Embed: Generate OpenAI embeddings
6. Index: Create ivfflat ANN indexes
7. Audit: Generate integrity reports

Make Targets (example for VA):
- make va-fetch              # Download guidelines
- make va-parse              # Parse into sections
- make va-rag-upsert         # Populate rag_corpus
- make va-embed              # Generate embeddings
- make va-ann                # Create ANN index
- make va-ci                 # Run integrity audit

================================================================================
CODING/ABSTRACTION PIPELINE
================================================================================

Endpoint: POST /api/rag/coding

Input: Clinical note text
Output: Structured JSON with:
- probable_dx: Primary diagnoses (ICD-10-CM)
- differential_dx: Differential diagnoses
- procedures: Recommended procedures (ICD-10-PCS)
- labs: Recommended labs (LOINC)
- medications: Recommended medications (RxNorm)
- insight: Clinical assessment

Process:
1. RAG retrieval from clinical note
2. LLM analysis with structured prompt
3. Code enrichment from matches
4. Citation governance
5. Output formats: JSON, CSV, PDF
