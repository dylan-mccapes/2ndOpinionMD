1
Idle-cycle trigger
When no active user query is running, the 8B model picks up background work. It selects the node with the lowest confidence or highest decay_score from the graph.
2
Neighborhood scan
The 8B reads the target node + its 2-hop neighborhood (medications, labs, encounters). It looks for implicit connections the 70B may have missed or that arrived after initial build.
3
Edge proposal
The model proposes new edges (e.g., medication → lab_result) with a confidence score. Only proposals above the 0.7 threshold are accepted.
4
Graph mutation + receipt
Accepted edges are written to the graph with full provenance: model=8b, reason=ogre_enrichment, confidence=0.82. The node's confidence score is updated.
5
Escalation gate
If the 8B finds a pattern it can't resolve (confidence < 0.5 after scan), it flags the node for 70B REVIEW — never guesses on high-stakes synthesis.
OGrE runs continuously on GPU 0 alongside 3.2 routing. It never interrupts active queries.
Every graph mutation is receipted: agent=ogre model=8b confidence=0.82 reason=lab_med_temporal_link
