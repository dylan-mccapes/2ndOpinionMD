## 3. Competitor Research (Major Theme)

### Guava Health — Most serious competitor

| Factor | Assessment |
|--------|------------|
| **Strengths** | Integrated records, symptom tracking, doctor summaries, health system integration, provider dashboards, corporate wellness offering |
| **Weaknesses** | Overwhelming feature set, not focused on autoimmune/chronic complexity, doesn't explain patterns deeply |
| **Strategic takeaway** | Validates the market; leaves room for differentiation |

### Visible — Pacing for chronic illness

| Factor | Assessment |
|--------|------------|
| **Strengths** | Clear daily loop, stability score, trend reports, doctor sharing, wearable integration |
| **Lessons for 2OPMD** | Daily habit loop, minimal logging friction, clear user payoff |

### Bearable — Symptom tracker

| Factor | Assessment |
|--------|------------|
| **Strengths** | Large download numbers, wide condition coverage |
| **Weaknesses** | Too broad (mental + physical), less specific to chronic illness |

## 4. Core Product Positioning for 2OPMD

### Central concept

**2OPMD = timeline intelligence system**

Not just: tracker · chatbot · journal

But a system that **turns messy health experiences into doctor-usable timelines.**

### Core user groups

1. **Undiagnosed / confused patients** — Need help organizing symptoms into hypotheses
2. **Diagnosed chronic patients** — Need help managing patterns and flare triggers

### Differentiation vs competitors

| Competitor | Strength | 2OPMD Advantage |
|------------|----------|-----------------|
| Guava | Tracking + records | Deeper interpretation |
| Visible | Pacing + daily loop | Broader autoimmune reasoning |
| Bearable | Symptom logging | Clinical narrative building |

## 5. Product Design Insights

### Daily engagement loop (inspired by Visible)

- Quick daily check-in
- Minimal symptom logging
- Journaling context
- System generates patterns
- Prepares doctor summaries

**Goal:** Give users a reason to open the app every day.

### "Tree of Life" idea

- Daily entries "water the tree"
- More data → stronger pattern detection
- Visible growth motivates continued use

### Flare tracking interaction

Potential UI mechanic:
- Tap/hold duration
- 1 sec → mild day
- 2 sec → bad day
- 3 sec → flare

Simple input instead of complex forms.

### Voice journaling

Optional voice memos for richer data capture.

## 6. EHR / Hospital Integration Discussion

**Cipher breakdown — three levels of connectivity:**

| Phase | Description | Implementation |
|-------|-------------|----------------|
| **Phase 1** | Manual upload: PDFs, photos, pasted text, journaling | Fastest launch |
| **Phase 2** | Patient-authorized portal access (SMART on FHIR, OAuth) via Epic, Cerner, Athenahealth, 1upHealth | Later |
| **Phase 3** | Provider workflow integration, clinician tools, hospital partnerships, enterprise compliance | Harder, slower |

**Cipher recommendation:** Start with manual upload + journaling. Add patient portal connections later.
