# PatientTimelineVision Embedding Strategy

**Version:** 1.0  
**Status:** Design Specification  
**Principle:** Embeddings are secondary to graph traversal; graph is source of truth

---

## CORE PRINCIPLES

```yaml
principles:
  - id: EMBED-001
    rule: "Embeddings are SECONDARY to graph traversal"
    rationale: "Graph provides structure, causality, provenance; embeddings provide semantic jump"
    
  - id: EMBED-002
    rule: "Every embedding MUST reference a backing node or subgraph (INV-003)"
    rationale: "No orphaned embeddings; every match traces back to graph"
    
  - id: EMBED-003
    rule: "Embeddings used STRATEGICALLY, not as primary storage"
    rationale: "Semantic search finds entry points; graph traversal provides context"
    
  - id: EMBED-004
    rule: "All semantic search results MUST map back to graph traversal"
    rationale: "Preserves provenance, enables causality, prevents hallucination"
    
  - id: EMBED-005
    rule: "Composite embeddings aggregate graph structure, not just text"
    rationale: "Capture relationships, not just isolated events"
```

## EMBEDDING LEVELS (3-Tier Strategy)

```
┌─────────────────────────────────────────────────────────────────────┐
│                     EMBEDDING HIERARCHY                             │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  LEVEL 1: NODE EMBEDDINGS (Atomic Events)                          │
│  ├─ Granularity: Single event (lab, med, note)                     │
│  ├─ Context: Graph neighbors (1-hop via edges)                     │
│  ├─ Use Case: Precise event retrieval                              │
│  └─ Storage: ptv.node_embeddings.event_id → single node            │
│                                                                     │
│  LEVEL 2: COMPOSITE EMBEDDINGS (Episodes/Arcs)                     │
│  ├─ Granularity: Flare episode, remission period, care arc         │
│  ├─ Context: All constituent events + edge structure               │
│  ├─ Use Case: Episode similarity, pattern matching                 │
│  └─ Storage: ptv.composite_embeddings.root_node_id → subgraph      │
│                                                                     │
│  LEVEL 3: PATIENT EMBEDDINGS (Global Signature)                    │
│  ├─ Granularity: Entire patient timeline                           │
│  ├─ Context: Summary of all arcs + key transitions                 │
│  ├─ Use Case: Case analog retrieval, cohort matching               │
│  └─ Storage: ptv.patient_embeddings.patient_id → full graph        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## NODE TYPES THAT GET EMBEDDINGS

### Tier 1: Always Embed (High Semantic Value)

```yaml
always_embed:
  - node_type: NOTE
    reason: "Rich narrative text, high semantic content"
    context_strategy: "Include referenced events (REFERENCES edges)"
    example: |
      Rheumatology note → embed with context of mentioned labs/meds
    
  - node_type: DERIVED_INSIGHT
    reason: "EoH-generated insights, high-level summaries"
    context_strategy: "Include all constituent events (COMPOSITE/DERIVED_FROM edges)"
    example: |
      Flare episode → embed with all labs/symptoms in episode
    
  - node_type: DECISION
    reason: "Clinical reasoning, treatment rationale"
    context_strategy: "Include causal upstream events (CAUSAL edges)"
    example: |
      "Start biologic" → embed with flare risk, lab values that triggered decision
```

### Tier 2: Conditionally Embed (Context-Dependent)

```yaml
conditionally_embed:
  - node_type: MEASUREMENT
    condition: "If high flare_signal_strength (> 0.7) OR referenced by NOTE"
    reason: "Only embed significant labs, not routine normals"
    context_strategy: "Include temporal neighbors (TEMPORAL_WINDOW)"
    example: |
      CRP=65 (high signal) → embed
      CRP=5 (normal, routine) → skip
    
  - node_type: MEDICATION_CHANGE
    condition: "If associated with DECISION or CAUSAL edges"
    reason: "Only embed when part of care plan reasoning"
    context_strategy: "Include triggering events (CAUSAL_LIKELY edges)"
    example: |
      MTX dose increase (linked to flare) → embed
      MTX dose increase (routine titration) → skip
    
  - node_type: RISK_SIGNAL
    condition: "Always (generated by EoH, high value)"
    reason: "Predictions are semantically rich"
    context_strategy: "Include contributing factors (PROVENANCE edges)"
    example: |
      Flare risk=high → embed with all contributing signals
```

### Tier 3: Never Embed (Low Semantic Value)

```yaml
never_embed:
  - node_type: EVENT (generic)
    reason: "Too vague; specific types (NOTE, MEASUREMENT) are better"
    
  - examples:
      - "Routine vitals (BP, HR) unless flagged"
      - "Appointment scheduling events"
      - "Administrative actions"
```

### Generation Strategy: Graph-Aware Context

```python
def generate_node_embedding(event_id: str, cur) -> Dict[str, Any]:
    """
    Generate embedding for a single node with graph context.
    
    Context Strategy:
    1. Node's own data (structured + text)
    2. 1-hop neighbors via strong edges (CAUSAL, REFERENCES, DERIVED_FROM)
    3. Temporal window neighbors (within 7 days)
    """
    # Fetch node
    cur.execute("""
        SELECT 
            event_id, node_type, event_subtype, timestamp,
            structured, text, annotations
        FROM ptv.event_node
        WHERE event_id = %s
    """, (event_id,))
    
    node = cur.fetchone()
    
    # Build context from graph neighbors
    context_nodes = []
    context_edges = []
    
    # 1-hop neighbors via strong edges
    cur.execute("""
        SELECT 
            n.event_id, n.node_type, n.event_subtype, n.text,
            e.relationship_type, e.strength
        FROM ptv.event_edge e
        JOIN ptv.event_node n ON (
            n.event_id = e.source_event_id OR 
            n.event_id = e.target_event_id
        )
        WHERE (e.source_event_id = %s OR e.target_event_id = %s)
          AND e.relationship_type IN ('causal_likely', 'references', 'derived_from', 'composite')
          AND e.strength > 0.7
          AND n.event_id != %s
        ORDER BY e.strength DESC
        LIMIT 5
    """, (event_id, event_id, event_id))
    
    for neighbor in cur.fetchall():
        context_nodes.append(neighbor)
    
    # Construct embedding text with graph context
    embedding_text = format_node_for_embedding(node, context_nodes)
    
    # Generate embedding
    embedding_vector = embed_text(embedding_text)  # OpenAI API call
    
    return {
        "event_id": event_id,
        "embedding": embedding_vector,
        "context_node_ids": [n[0] for n in context_nodes],
        "context_edge_types": list(set(n[4] for n in context_nodes)),
        "context_window_size": len(context_nodes),
    }

def format_node_for_embedding(node, context_nodes) -> str:
    """
    Format node + context for embedding.
    
    Structure:
    [Primary Event]
    <node details>
    
    [Graph Context]
    - Related via <edge_type>: <neighbor summary>
    - Related via <edge_type>: <neighbor summary>
    """
    event_id, node_type, subtype, timestamp, structured, text, annotations = node
    
    lines = [
        f"[Primary Event: {node_type}]",
        f"Subtype: {subtype}",
        f"Timestamp: {timestamp.isoformat()}",
        f"Data: {json.dumps(structured)}",
        f"Text: {text}",
    ]
    
    if annotations:
        lines.append(f"EoH Annotations: {json.dumps(annotations)}")
    
    if context_nodes:
        lines.append("\n[Graph Context]")
        for ctx in context_nodes:
            ctx_id, ctx_type, ctx_subtype, ctx_text, edge_type, strength = ctx
            lines.append(
                f"- Related via {edge_type} (strength={strength:.2f}): "
                f"{ctx_type}/{ctx_subtype} - {ctx_text[:100]}"
            )
    
    return "\n".join(lines)
```

### Generation Strategy: Subgraph Aggregation

```python
def generate_composite_embedding(root_node_id: str, cur) -> Dict[str, Any]:
    """
    Generate embedding for a DERIVED_INSIGHT node (e.g., flare episode).
    
    Aggregation Strategy:
    1. Root node (flare episode summary)
    2. All constituent events (via COMPOSITE/DERIVED_FROM edges)
    3. Key transitions (med changes, decision points)
    4. Structural features (duration, severity, outcome)
    """
    # Fetch root node (must be DERIVED_INSIGHT)
    cur.execute("""
        SELECT event_id, structured, annotations
        FROM ptv.event_node
        WHERE event_id = %s AND node_type = 'derived_insight'
    """, (root_node_id,))
    
    root = cur.fetchone()
    if not root:
        raise ValueError(f"Node {root_node_id} is not a DERIVED_INSIGHT")
    
    # Fetch constituent events (via COMPOSITE/DERIVED_FROM edges)
    cur.execute("""
        SELECT 
            n.event_id, n.node_type, n.event_subtype, 
            n.timestamp, n.structured, n.text,
            e.relationship_type
        FROM ptv.event_edge e
        JOIN ptv.event_node n ON n.event_id = e.source_event_id
        WHERE e.target_event_id = %s
          AND e.relationship_type IN ('composite', 'derived_from')
          AND n.status = 'included'
        ORDER BY n.timestamp
    """, (root_node_id,))
    
    constituents = cur.fetchall()
    
    # Build structural summary
    structure = {
        "constituent_count": len(constituents),
        "duration_days": (constituents[-1][3] - constituents[0][3]).days if len(constituents) > 1 else 0,
        "node_types": list(set(c[1] for c in constituents)),
        "key_subtypes": list(set(c[2] for c in constituents if c[2])),
    }
    
    # Aggregate into narrative
    embedding_text = format_composite_for_embedding(root, constituents, structure)
    
    # Generate embedding
    embedding_vector = embed_text(embedding_text)
    
    return {
        "root_node_id": root_node_id,
        "constituent_node_ids": [c[0] for c in constituents],
        "edge_count": len(constituents),
        "structure_summary": structure,
        "embedding": embedding_vector,
    }

def format_composite_for_embedding(root, constituents, structure) -> str:
    """
    Format composite node for embedding.
    
    Structure:
    [Episode Summary]
    <root insight>
    
    [Structural Features]
    Duration: X days
    Event count: Y
    Key transitions: ...
    
    [Constituent Events]
    - Event 1: ...
    - Event 2: ...
    """
    root_id, root_structured, root_annotations = root
    
    lines = [
        f"[Episode Summary]",
        f"Type: {root_structured.get('insight_type')}",
        f"Summary: {root_structured.get('insight_summary')}",
        f"Confidence: {root_structured.get('confidence')}",
        "",
        f"[Structural Features]",
        f"Duration: {structure['duration_days']} days",
        f"Constituent events: {structure['constituent_count']}",
        f"Event types: {', '.join(structure['node_types'])}",
        f"Key subtypes: {', '.join(structure['key_subtypes'])}",
        "",
        f"[Constituent Events]",
    ]
    
    for const in constituents:
        _, node_type, subtype, timestamp, structured, text, _ = const
        lines.append(
            f"- {timestamp.date()}: {node_type}/{subtype} - "
            f"{text[:100] if text else json.dumps(structured)[:100]}"
        )
    
    return "\n".join(lines)
```

def generate_patient_embedding(patient_id: str, cur) -> Dict[str, Any]:
    """
    Generate global embedding for entire patient timeline.
    
    Aggregation Strategy:
    1. Key clinical arcs (flare episodes, remission periods)
    2. Medication trajectory (DMARD sequence, biologics)
    3. Diagnostic landscape evolution
    4. Major transitions and inflection points
    """
    # Fetch key arcs (DERIVED_INSIGHT nodes)
    cur.execute("""
        SELECT event_id, event_subtype, timestamp, structured, annotations
        FROM ptv.event_node
        WHERE patient_id = %s
          AND node_type = 'derived_insight'
          AND status = 'included'
        ORDER BY timestamp
    """, (patient_id,))
    
    key_arcs = cur.fetchall()
    
    # Fetch medication trajectory
    cur.execute("""
        SELECT event_id, timestamp, structured->>'drug_name', structured->>'action'
        FROM ptv.event_node
        WHERE patient_id = %s
          AND node_type = 'medication_change'
          AND status = 'included'
        ORDER BY timestamp
    """, (patient_id,))
    
    meds = cur.fetchall()
    
    # Build signature features
    signature = {
        "flare_pattern": analyze_flare_pattern(key_arcs),
        "medication_trajectory": analyze_med_trajectory(meds),
        "disease_duration_days": calculate_duration(patient_id, cur),
        "inflection_points": count_inflection_points(patient_id, cur),
    }
    
    # Aggregate into patient narrative
    embedding_text = format_patient_for_embedding(patient_id, key_arcs, meds, signature)
    
    # Generate embedding
    embedding_vector = embed_text(embedding_text)
    
    return {
        "patient_id": patient_id,
        "signature_features": signature,
        "key_arcs": [{"id": a[0], "type": a[1], "timestamp": a[2].isoformat()} for a in key_arcs],
        "embedding": embedding_vector,
    }

## SEMANTIC SEARCH → GRAPH TRAVERSAL MAPPING

### Architecture

```
┌─────────────────────────────────────────────────────────────────────┐
│                         QUERY FLOW                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  User Query: "Find patients with seasonal flare pattern"           │
│       ↓                                                             │
│  [1. SEMANTIC JUMP]                                                 │
│   Embed query → vector search → Top-K patient embeddings           │
│   Result: [P001, P042, P127] (3 similar patients)                  │
│       ↓                                                             │
│  [2. GRAPH ENTRY]                                                   │
│   For each patient, load PatientTimelineVision graph               │
│   Entry point: patient_id → ptv.event_node                         │
│       ↓                                                             │
│  [3. GRAPH TRAVERSAL]                                               │
│   Navigate graph to verify "seasonal" pattern:                     │
│   - Find flare_episode nodes (DERIVED_INSIGHT)                     │
│   - Check timestamps (months of year)                              │
│   - Traverse COMPOSITE edges to constituent events                 │
│   - Traverse SIMILARITY edges between episodes                     │
│       ↓                                                             │
│  [4. PROVENANCE TRACE]                                              │
│   For each matched episode:                                        │
│   - Traverse backward via CAUSAL edges                             │
│   - Identify triggers (meds, weather, labs)                        │
│   - Extract confidence scores from edges                           │
│       ↓                                                             │
│  [5. STRUCTURED ANSWER]                                             │
│   Return graph-backed evidence:                                    │
│   - Patient IDs with provenance                                    │
│   - Specific flare episodes (node IDs)                             │
│   - Causal chains (edge paths)                                     │
│   - Confidence scores (from graph metadata)                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Implementation: Hybrid Search

```python
def hybrid_search(
    query: str,
    search_level: str = "patient",  # "node", "composite", "patient"
    top_k: int = 10,
    min_graph_confidence: float = 0.7,
) -> List[Dict[str, Any]]:
    """
    Hybrid search: Semantic jump + graph traversal.
    
    Steps:
    1. Semantic search finds candidates (vector similarity)
    2. Graph traversal verifies and enriches results
    3. Return structured results with provenance
    """
    # Step 1: Semantic jump (vector search)
    query_embedding = embed_text(query)
    
    if search_level == "patient":
        candidates = vector_search_patients(query_embedding, top_k=top_k)
    elif search_level == "composite":
        candidates = vector_search_composites(query_embedding, top_k=top_k)
    else:
        candidates = vector_search_nodes(query_embedding, top_k=top_k)
    
    # Step 2: Graph traversal for each candidate
    results = []
    for candidate in candidates:
        # Load graph context
        if search_level == "patient":
            graph_context = load_patient_graph(candidate["patient_id"])
        elif search_level == "composite":
            graph_context = load_composite_subgraph(candidate["root_node_id"])
        else:
            graph_context = load_node_context(candidate["event_id"])
        
        # Verify via graph (prevents hallucination)
        verification = verify_via_graph(query, graph_context)
        
        if verification["confidence"] >= min_graph_confidence:
            results.append({
                "candidate": candidate,
                "graph_context": graph_context,
                "verification": verification,
                "provenance": extract_provenance(graph_context),
            })
    
    # Step 3: Rank by graph confidence (not just embedding similarity)
    results.sort(key=lambda x: x["verification"]["confidence"], reverse=True)
    
    return results

def vector_search_patients(query_embedding, top_k: int):
    """Vector search over patient embeddings"""
    cur.execute("""

## COMPARISON: NAIVE RAG vs GRAPH-AWARE EMBEDDINGS

### Table

| Aspect | Naive RAG (Timeline Text) | PTV Graph-Aware Embeddings |
|--------|---------------------------|----------------------------|
| **Storage** | Text chunks in vector DB | Graph nodes + embeddings reference graph |
| **Context** | Fixed-size text window | Graph neighbors via edges (dynamic) |
| **Causality** | Not represented | Explicit CAUSAL edges with confidence |
| **Provenance** | None (chunk has no lineage) | Full (event_id → discovered_by, edge metadata) |
| **Verification** | No way to verify claims | Graph traversal verifies all claims |
| **Hallucination** | High risk (LLM invents facts) | Low risk (graph grounds all answers) |
| **Composite Events** | Not possible (events isolated) | Native (DERIVED_INSIGHT + COMPOSITE edges) |
| **Similarity Search** | Text similarity only | Structural + semantic similarity |
| **Explanation** | "LLM said so" | "Graph shows evt_X → evt_Y via CAUSAL edge (conf=0.85, M4)" |
| **Temporal Reasoning** | Weak (inferred from text) | Strong (TEMPORAL_SEQUENCE/WINDOW edges) |
| **Multi-Hop Queries** | Not supported | Native (graph traversal) |

```
